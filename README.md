# Отчёт по авансам договоров

CLI на Python: по выгрузкам договоров, работ и платежей строит отчёт **на дату** — сколько уже выплачено и сколько осталось по каждой работе и по каждому договору.

Исходное условие тестового задания: [`ASSIGNMENT.md`](ASSIGNMENT.md).

## Зачем

Бухгалтеру нужны цифры «за что уже рассчитались», хотя часть платежей — авансы по договору без привязки к работе. Программа:

1. Отбирает платежи, которые на дату реально ушли подрядчику.
2. Восстанавливает статусы работ на эту дату.
3. Платежи с `work_id` зачисляет на работу; остальной пул разносит **FIFO** (сначала принятые работы, потом запланированные).
4. Печатает две таблицы: работы и договоры.

Деньги считаются через `decimal.Decimal` (без `float`).

## Быстрый старт

```bash
python3 -m report --date 2026-11-10 --data data
```

Опционально CSV:

```bash
python3 -m report --date 2026-11-10 --data data --csv out
```

Тесты:

```bash
python3 -m pytest -q
```

Нужен Python 3.9+. Зависимостей кроме `pytest` для тестов нет.

## Как считается отчёт

| Тема | Правило |
|---|---|
| Дата | Включительно (`<= as_of`) |
| `paid` | В «выплачено», если `paid_at <= as_of` |
| `queued` | Не в «выплачено»; отдельная колонка у договора |
| `refunded` | В «выплачено» только пока `refunded_at > as_of` |
| Статус работы | По `cancelled_at` / `completed_at` на дату, не слепо из CSV |
| Cancelled | Цена обязательства 0, в FIFO не участвует |
| Аванс без работы | FIFO: done по дате принятия → planned по `work_id` |

Контрольная дата из задания: **2026-11-10**.

Пример итогов на эту дату:

- **D-1** (Студия «Свет»): выплачено 315 000 ₽, осталось по работам 185 000 ₽, в очереди 150 000 ₽.
- **D-2** (Иван Петров): выплачено 75 000 ₽, осталось 15 000 ₽ (упаковка ещё не принята на 10.11).

## Колонки вывода

**Работы:** `price`, `paid`, `remain`, `linked` (платежи с `work_id`), `pool` (доля аванса), `status`, название.

**Договоры:** сумма договора, сумма цен активных работ, `paid`, `remain`, `unalloc` (неразнесённый пул), `queued`, подрядчик.
